Pourquoi Hyprland ?

ℹ️
Hyprland est un compositeur Wayland moderne avec tiling dynamique, animations fluides et forte personnalisation. Il n'est pas dans les dépôts Debian 12 — on le compile depuis les sources via un hook live-build. C'est ce qui rendra TérangaOS unique.

📄 build.sh — Script principal

terangaos/build.sh
bash 
#!/bin/bash
set -e

echo "╔══════════════════════════════════════════╗"
echo "║   TérangaOS Build System v1.0            ║"
echo "║   Codename: Djolof · Base: Debian 12     ║"
echo "╚══════════════════════════════════════════╝"

# ── 1. Vérification des dépendances ──
echo "[1/7] Vérification des dépendances..."
for tool in lb debootstrap git curl wget cmake ninja-build; do
  command -v $tool &>/dev/null || {
    echo "[ERREUR] Outil manquant: $tool"
    echo "Lancer: sudo apt install live-build debootstrap git curl wget cmake ninja-build"
    exit 1
  }
done
echo "  ✓ Tous les outils présents"

# ── 2. Nettoyage ──
echo "[2/7] Nettoyage du build précédent..."
sudo lb clean --purge 2>/dev/null || true

# ── 3. Configuration live-build ──
echo "[3/7] Configuration TérangaOS..."
lb config \
  --distribution bookworm \
  --architecture amd64 \
  --binary-images iso-hybrid \
  --debian-installer live \
  --locale fr_FR.UTF-8 \
  --timezone Africa/Dakar \
  --hostname terangaos \
  --username teranga \
  --apt-recommends false \
  --linux-packages "linux-image linux-headers" \
  --bootappend-live "boot=live components locales=fr_FR.UTF-8 keyboard-layouts=fr" \
  --iso-volume "TérangaOS 1.0 Djolof" \
  --iso-publisher "ESP/UCAD Dakar — TérangaOS Project"

# ── 4. Package Lists ──
echo "[4/7] Création des package lists..."
mkdir -p config/package-lists config/hooks/live config/includes.chroot/etc

# Base système
cat > config/package-lists/base.list.chroot << 'EOF'
systemd systemd-sysv dbus
pipewire pipewire-audio pipewire-alsa wireplumber
network-manager network-manager-gnome
polkit polkit-gnome

firefox-esr
EOF

# Desktop Hyprland + Wayland
cat > config/package-lists/desktop.list.chroot << 'EOF'
wayland-utils xwayland

sddm
qt5-wayland qt6-wayland

imv

EOF

# Cybersécurité
cat > config/package-lists/cybersec.list.chroot << 'EOF'

# Développement
cat > config/package-lists/dev.list.chroot << 'EOF'

# IA — les paquets pip sont installés via hook
cat > config/package-lists/ai.list.chroot << 'EOF'
python3-torch

python3-numpy

EOF

# ── 5. Hooks ──
echo "[5/7] Écriture des hooks..."
./scripts/write-hooks.sh

# ── 6. Configs Hyprland & thème ──
echo "[6/7] Injection des configs Hyprland..."
./scripts/inject-configs.sh

# ── 7. Build ISO ──
echo "[7/7] Construction de l'ISO (peut prendre 30-90 min)..."
sudo lb build 2>&1 | tee build.log

# ── Résultat ──
ISO_FILE=$(ls *.iso 2>/dev/null | head -1)
if [ -n "$ISO_FILE" ]; then
  mv "$ISO_FILE" "terangaos-1.0-amd64.iso"
  sha256sum terangaos-1.0-amd64.iso > terangaos-1.0.sha256
  echo ""
  echo "╔══════════════════════════════════════════╗"
  echo "║  ✅ TérangaOS ISO générée avec succès!   ║"
  echo "║  → terangaos-1.0-amd64.iso              ║"
  echo "╚══════════════════════════════════════════╝"
  ls -lh terangaos-1.0-amd64.iso
else
  echo "[ERREUR] Build échoué. Voir build.log"
  exit 1
fi

📄 Hook — Compilation Hyprland depuis source

config/hooks/live/0002-hyprland-build.hook.chroot
bash 
#!/bin/bash
set -e
echo "[HOOK] Compilation Hyprland + composants hyprwm..."

# Dépendances de compilation Hyprland
apt-get install -y \
  libwayland-dev libwayland-egl1 libwayland-server0 \
  libxkbcommon-dev libxkbcommon-x11-dev \
  libegl1-mesa-dev libgles2-mesa-dev \
  libdrm-dev libgbm-dev \
  libpango1.0-dev libcairo2-dev \
  libseat-dev libinput-dev \
  libudev-dev libsystemd-dev \
  libpixman-1-dev \
  libvulkan-dev glslang-dev \
  libtomlplusplus-dev \
  librsvg2-dev \
  hwdata libdisplay-info-dev \
  meson cmake ninja-build pkg-config \
  git curl

# Cloner et compiler Hyprland
cd /tmp
git clone --recursive https://github.com/hyprwm/Hyprland --branch v0.41.0
cd Hyprland

echo "[HOOK] Configuration Hyprland..."
cmake -B build \
  -DCMAKE_BUILD_TYPE=Release \
  -DCMAKE_INSTALL_PREFIX=/usr \
  -G Ninja

echo "[HOOK] Compilation en cours (peut prendre 15-30 min)..."
cmake --build build -j$(nproc)
cmake --install build

# Hyprpaper
echo "[HOOK] Compilation Hyprpaper..."
cd /tmp
git clone https://github.com/hyprwm/hyprpaper --branch v0.7.0
cd hyprpaper
cmake -B build -DCMAKE_BUILD_TYPE=Release -DCMAKE_INSTALL_PREFIX=/usr -G Ninja
cmake --build build -j$(nproc)
cmake --install build

# Hyprlock
echo "[HOOK] Compilation Hyprlock..."
cd /tmp
git clone https://github.com/hyprwm/hyprlock --branch v0.5.0
cd hyprlock
cmake -B build -DCMAKE_BUILD_TYPE=Release -DCMAKE_INSTALL_PREFIX=/usr -G Ninja
cmake --build build -j$(nproc)
cmake --install build

# Nettoyage sources
rm -rf /tmp/Hyprland /tmp/hyprpaper /tmp/hyprlock

echo "[HOOK] Hyprland $(Hyprland --version) installé ✓"

#!/bin/bash
set -e

# Créer l'utilisateur principal
useradd -m -s /bin/zsh -G sudo,video,audio,input,netdev,plugdev teranga

# root sans mot de passe sur live

# Oh My Zsh pour teranga
su - teranga -c 'sh -c "$(curl -fsSL https://raw.githubusercontent.com/ohmyzsh/ohmyzsh/master/tools/install.sh)" "" --unattended'

# Plugins zsh
su - teranga -c 'git clone https://github.com/zsh-users/zsh-autosuggestions ~/.oh-my-zsh/custom/plugins/zsh-autosuggestions'
su - teranga -c 'git clone https://github.com/zsh-users/zsh-syntax-highlighting ~/.oh-my-zsh/custom/plugins/zsh-syntax-highlighting'

# .zshrc thémé TérangaOS
cat > /home/teranga/.zshrc << 'ZSHRC'
export ZSH="$HOME/.oh-my-zsh"
ZSH_THEME="agnoster"
plugins=(git zsh-autosuggestions zsh-syntax-highlighting docker)
source $ZSH/oh-my-zsh.sh
export LANG=fr_FR.UTF-8
export EDITOR=nano
alias ll='ls -la --color=auto'
alias update='sudo apt update && sudo apt upgrade -y'
alias cybertools='ls /usr/bin/nmap /usr/bin/wireshark /usr/bin/aircrack-ng'

echo "Bienvenue sur TérangaOS 🌍 — Dalal ak diam"

Depuis Windows

Construire depuis Windows

⚠️
Hyprland compile depuis les sources — le build complet prend 1h à 3h selon ton CPU. Assure-toi d'avoir au moins 8 Go RAM, 4 cœurs et 80 Go d'espace disque disponibles.
01
Installer WSL2 + Debian
Ouvre PowerShell en administrateur et installe WSL2 avec Debian comme distribution.
PowerShell — Administrateurpowershell
# Activer WSL2
wsl --install
wsl --install -d Debian

# Définir WSL2 par défaut
wsl --set-default-version 2

# Vérifier
wsl --list --verbose
02
Préparer l'environnement de build dans WSL2
Dans le terminal Debian WSL2, installe toutes les dépendances nécessaires.
WSL2 — Debian bashbash
# Mise à jour système
sudo apt update && sudo apt upgrade -y

# Outils de build TérangaOS
sudo apt install -y \
  live-build debootstrap \
  git curl wget \
  build-essential cmake ninja-build pkg-config \
  meson \
  libwayland-dev libxkbcommon-dev \
  libegl1-mesa-dev libgles2-mesa-dev \
  libdrm-dev libgbm-dev \
  libseat-dev libinput-dev libudev-dev \
  libpixman-1-dev libvulkan-dev \
  glslang-dev libpango1.0-dev \
  libcairo2-dev libsystemd-dev \
  hwdata libdisplay-info-dev \
  squashfs-tools xorriso isolinux

# Vérifier live-build
lb --version
03
Cloner le projet TérangaOS
Crée la structure du projet et copie tous les scripts de ce guide.
WSL2bash
# Créer le répertoire de travail
mkdir -p ~/terangaos/config/{package-lists,hooks/live,includes.chroot}
mkdir -p ~/terangaos/config/includes.chroot/etc
mkdir -p ~/terangaos/config/includes.chroot/home/teranga/.config/{hypr,waybar,kitty,wofi,mako}
mkdir -p ~/terangaos/config/includes.chroot/usr/share/{backgrounds/terangaos,grub/themes/terangaos}
cd ~/terangaos

# Copier les scripts de l'onglet "Build Scripts"
# → build.sh, hooks, package-lists
chmod +x build.sh config/hooks/live/*.hook.chroot
04
Injecter les configs Hyprland
Copie les fichiers de l'onglet "Hyprland" et "Thème" dans les bons répertoires includes.chroot.
WSL2bash
BASE=~/terangaos/config/includes.chroot/home/teranga/.config # Créer hyprland.conf (copier depuis onglet Hyprland) nano $BASE/hypr/hyprland.conf # Créer waybar config + style nano $BASE/waybar/config.jsonc nano $BASE/waybar/style.css # Kitty theme nano $BASE/kitty/kitty.conf # Wofi style nano $BASE/wofi/style.css # Mako notifications nano $BASE/mako/config
05
Lancer le build
Lance le build principal. Durée estimée : 1h à 3h selon ta connexion et ton CPU.
WSL2 — dans ~/terangaosbash
cd ~/terangaos sudo bash build.sh 2>&1 | tee build.log # Suivre la progression en temps réel tail -f build.log
06
Récupérer l'ISO et tester dans VirtualBox
L'ISO est générée dans ~/terangaos/. Copie-la vers Windows puis boot dans VirtualBox.
WSL2 → Windowsbash
# Copier l'ISO vers le bureau Windows cp ~/terangaos/terangaos-1.0-amd64.iso /mnt/c/Users/$USER/Desktop/ # Vérifier l'intégrité sha256sum terangaos-1.0-amd64.iso
ℹ️
Dans VirtualBox : Nouvelle VM → Linux/Debian 64-bit → 4 Go RAM → 40 Go disque → Activer EFI → Démarrer depuis l'ISO TérangaOS. Hyprland nécessite une accélération 3D → activer dans Affichage → Mémoire vidéo 128 Mo.
