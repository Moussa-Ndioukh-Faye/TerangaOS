Plan de travail

Roadmap de construction

01
Environnement de build
Installer les outils de build sur une machine Debian. Configurer live-build (outil officiel Debian pour créer des ISO live). Préparer la structure du projet Git.
live-build debootstrap git init Debian 12 Bookworm
02
Configuration de la base
Définir les paramètres de l'ISO : architecture (amd64), langue (fr_FR), locale, fuseau horaire (Africa/Dakar), hostname terangaos. Configurer le dépôt APT.
lb config locale fr_FR.UTF-8 Africa/Dakar KDE Plasma 6
03
Package lists — Les 3 piliers
Créer les fichiers de liste de paquets pour chaque pilier. Ajouter les scripts post-install pour Ollama, Open WebUI, Metasploit (pas dans APT officiel).
package-lists/ hooks/ curl | sh (Ollama) msfinstall
04
Theming & Branding KDE
Appliquer la palette TérangaOS sur KDE Plasma : fond d'écran personnalisé, thème Kvantum, icônes Papirus (orange), GRUB themé, splash screen Plymouth.
Kvantum Papirus-icon-theme Plymouth GRUB theme
05
Build & Test en VM
Lancer lb build pour générer l'ISO. Tester dans VirtualBox ou QEMU. Corriger les erreurs de build itérativement. Vérifier le boot UEFI + BIOS.
lb build VirtualBox / QEMU UEFI + Legacy BIOS live-boot
06
Packaging final & Livraison
Générer l'ISO finale (~4-6 Go). Calculer le SHA256. Rédiger la documentation utilisateur en français. Préparer la soutenance avec démo live.
terangaos-1.0-amd64.iso sha256sum README.md Démo live ESP/UCAD
