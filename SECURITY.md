# Security Policy — TérangaOS

## Reporting a Vulnerability

Si vous découvrez une vulnérabilité dans TérangaOS, merci de la signaler par email à l'équipe de sécurité plutôt que de créer une issue publique.

**Email** : (à définir — ouvrir une issue GitHub pour être contacté)

Ne pas divulguer la vulnérabilité publiquement avant qu'un correctif ne soit disponible.

## Supply Chain

TérangaOS vérifie l'intégrité des sources téléchargées via SHA256.
Les ISOs publiées sont accompagnées de :
- Checksum SHA256
- Signature GPG (à partir de v1.1)

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | ✅ Active          |
| < 1.0   | ❌ Pre-release     |
